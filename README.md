# Brain — Отделы головного мозга

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Интерактивное веб-приложение для изучения строения и функций отделов головного мозга.  
Проект представляет собой одностраничное приложение (SPA) на чистом HTML, CSS и JavaScript без внешних зависимостей.

## 🚀 Демо
**Открыть приложение: [https://tihonbest.github.io/brain/](https://tihonbest.github.io/brain/)**

## Возможности

### 🧠 Два режима обучения

**1. Учение (без оценки)**
- Показывается схема мозга с выделенным отделом.
- Нужно выбрать правильное название из четырёх вариантов.
- Затем для каждого утверждения о функциях отдела выбрать «Верно» / «Неверно».
- Сразу после ответа появляется обратная связь с пояснениями.
- В конце — сводка: сколько названий и функций определено верно.
- Можно повторить только те отделы, где были ошибки.

**2. Проверка знаний (с оценкой)**
- Название отдела нужно вписать самостоятельно (поддерживается проверка на опечатки).
- Отметить верные и неверные утверждения о функциях.
- После прохождения всех 9 вопросов — результат в процентах, оценка по шкале (2–5) и разбор ошибок.

### 📖 Справочник
- Интерактивная схема мозга (срединный разрез).
- Можно нажать на отдел на схеме или выбрать его из списка.
- Показывается расположение, краткое описание и список функций.

### 🎨 Интерфейс
- Стиль «liquid glass» с анимированным фоном-авророй.
- Светлая и тёмная темы (с учётом системных настроек).
- Адаптивная вёрстка для мобильных и десктопных устройств.
- Доступность: клавиатурная навигация, ARIA-атрибуты, поддержка `prefers-reduced-motion`.

## Технологии
- **HTML5** — семантическая разметка.
- **CSS3** — кастомные свойства, `backdrop-filter`, анимации, адаптивность, тёмная тема.
- **Vanilla JavaScript** — без фреймворков и библиотек.
